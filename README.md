# Exception-Handling-
Exceptions are handled in three different ways 1.Handling the Exception(try-catch) 2.Re-throwing an Exception(try, catch, finally, throw, trhows) 3.Ducking an Exception(throws)


Handling an Exception – Catching and resolving the exception within the same method where it occurs.

Rethrowing an Exception – Catching an exception, performing some action, and then throwing it again so the caller can also handle it.

Ducking (Propagating) an Exception – Declaring an exception with throws and passing the responsibility of handling it to the calling method.
